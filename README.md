Movie Recommender

A cozy little movie recommendation engine that finds films similar to your favorites. Pick a movie, hit the button, and discover your next watch.

What It Does

Select any movie from the dropdown, click "Show Recommendation", and get a curated row of similar films with posters. Simple, visual, and fun.
How it works: The system uses content-based filtering (genres, keywords, cast, crew, and plot overviews) to compute similarity scores between movies and surface the closest matches.

| Select a Movie              | Get Recommendations          |
| --------------------------- | ---------------------------- |
| Dropdown with 5,000+ titles | 5 similar films with posters |


 Dataset
Built on the TMDB 5000 Movies Dataset — 5,000 movies with metadata, cast, crew, and keywords.
